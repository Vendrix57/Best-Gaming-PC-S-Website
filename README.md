# HardwareDealz - Gaming PC Recommendations

A modern, responsive web application designed to help gamers find the best PC configurations for their budget. HardwareDealz provides curated build lists ranging from entry-level to high-end enthusiast setups.

## 🌐 Live Demo
*https://vendrix57.github.io/Best-Gaming-PC-Website/*

## ✨ Features

* **Visual Hardware Catalog:** A grid-based layout showcasing the best PC builds from €800 to high-end enthusiast tiers.
* **Detailed Specifications:** Each build provides at-a-glance info for CPU, GPU, and RAM.
* **Modern UI/UX:**
    * **Glassmorphism:** Semi-transparent containers with backdrop blurring for a premium look.
    * **Interactive Elements:** Hover effects including scaling and neon glowing borders.
    * **Custom Branding:** Unique hardware-themed aesthetic with a custom "HardwareDealz" logo and color palette.
* **Responsive Design:** Built using CSS Grid and Flexbox to ensure accessibility across various screen sizes.

## 🛠️ Built With

* **HTML5:** Semantic structure for the landing and product pages.
* **CSS3:** Advanced styling including linear gradients, animations, and transitions.
* **Google Fonts:** Utilizes clean, modern typography like Arial and Lucida Sans.
